# giong brand assets

The giong mark is an iron horse — from the legend of Thánh Gióng — whose mane is a
segmented ring: the io_uring ring buffer, with the lit segments running ahead like a
comet. Colours: ember orange `#FF6A2B`, off-white `#E9EDF2`, ink `#0A0C10`. The
wordmark is set in Inter Display ExtraBold and stored as outlines, so it renders the
same everywhere.

| File | Use |
|---|---|
| `giong-logo-dark.svg` | Horizontal logo for dark backgrounds |
| `giong-logo-light.svg` | Horizontal logo for light backgrounds |
| `giong-mark.svg` | Mark only, transparent, for dark backgrounds |
| `giong-mark-light.svg` | Mark only, transparent, for light backgrounds |
| `giong-mark-dark.svg` | Mark on a dark tile |
| `giong-icon.svg`, `giong-icon-180.png`, `giong-icon-512.png`, `favicon.ico` | App icon, avatar, favicon |
| `social-preview.png` | GitHub social preview, 1280×640 |

The README picks the light or dark logo from the reader's colour scheme.

To use the social preview, upload `social-preview.png` in the repository's
Settings → General → Social preview.
